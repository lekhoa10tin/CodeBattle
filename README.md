# 🎮 Code Odyssey - Algorithm RPG Game

Một tựa web game nhập vai kết hợp luyện tập thuật toán C++ trực quan. 

## 🚀 Tính năng
- Game engine 2D render bằng **Phaser.js**.
- Trình soạn thảo code C++ tích hợp **Monaco Editor** (VS Code engine).
- Giải thuật toán thực tế (Binary Search, DP, Graph...) để vượt chướng ngại vật trong game.

## 🛠️ Tech Stack
- Frontend: HTML5, CSS3, JavaScript
- Libraries: Phaser 3, Monaco Editor
